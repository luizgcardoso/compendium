# Como iniciar um projeto fullstack?

    ```bash
        // instale o npm. Em seguida, digite os comandos abaixo no terminal
       
        npm init -y

        // Esse comando instala a ferrementa e salva como dependencia de desenvolvimento. Ex: typescript
        npm install --save-dev tipescript @types/nodes

    ```

# Como iniciar um projeto fullstack?
   -  Podemos começar escolhendo entre duas opções de estruturação de projeto:
      * Um único repositório (monorepo)    
      * Dois repositórios
